# JetBrains Mono

Bundled from the official [JetBrains Mono v2.304 release](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf).

Included styles: Regular (400), Italic (400), Medium (500), SemiBold (600), Bold (700).
The app loads these local assets on macOS and Windows without downloading fonts at runtime.
